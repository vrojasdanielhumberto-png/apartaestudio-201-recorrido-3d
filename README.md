# Apartaestudio 201 · Recorrido 3D

Página de venta con recorrido 3D interactivo de un apartamento real (32,24 m²). Mientras bajas, la cámara recorre cada espacio, se abren solos el closet, los gabinetes, la ventana y el balcón, y cada espacio muestra sus medidas.

**Verlo en vivo:** https://vrojasdanielhumberto-png.github.io/apartaestudio-201-recorrido-3d/

## Cómo está hecho

- Modelo armado en código con [Three.js](https://threejs.org) a partir del plano con medidas y un video del apartamento.
- Luz horneada por vértice (cielo por las ventanas, sol y rebotes) para que se vea realista y corra bien en celulares.
- Las vistas por las ventanas son fotos de [Unsplash](https://unsplash.com): [balcón](https://unsplash.com/photos/sunlight-filters-through-lush-green-trees-in-a-park-UIqDr16kZzY) y [sala](https://unsplash.com/photos/lush-green-park-with-tall-trees-and-a-path-nR5aL-TSh1k).
- Imagen nítida en reposo: mientras se baja se dibuja liviano y, al quedarse quieta, se redibuja en alta resolución.
- Sin servidor ni compilación: HTML y JavaScript estáticos.

Los precios, la ubicación, las zonas comunes y el contacto son datos de ejemplo para la demo.
